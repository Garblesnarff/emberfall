# EMBERFALL Versioning

EMBERFALL uses SemVer-style pre-1.0 numbering:

- `0.MINOR.PATCH`
- Minor versions mark completed implementation phases.
- Patch versions mark fixes or small improvements within the current phase.

Current version: `0.5.7`

## Phase Mapping

- `0.1.0` - Phase 1 Core Port
- `0.2.0` - Phase 2 World
- `0.3.0` - Phase 3 Systems
- `0.4.0` - Phase 4 Meta & Bosses
- `0.5.0` - Phase 5 Steam & Polish
- `0.6.0` - Phase 6 Art Integration
- `0.7.0` - Phase 7 Release Prep
